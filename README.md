# Week 1 Log Counter

This is a simple Python program that reads a log file and counts how many `INFO`, `WARN`, and `ERROR` messages are present.

## What I learned

- Reading files in Python
- Using loops
- Using dictionaries
- Handling missing files with `try` and `except`
- Writing modular Python code

## How to run

```bash
python week1_log_counter.py

Then enter the log file name: app.log

Example output

Below are each log counts
INFO: 9
WARN: 3
ERROR: 3

week1_log_counter.py - main Python program
